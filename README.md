# Sweet Treats by Abigail

A modern, responsive bakery website developed for **Sweet Treats by Abigail**, a home-based bakery located in **Booysens Park, Gqeberha (Port Elizabeth), South Africa**.

The website showcases the bakery's products, provides information about the business, displays the bakery's location, and allows customers to submit enquiries for custom cake orders.

# About the Project

Sweet Treats by Abigail is a bakery that specialises in handcrafted cakes and desserts for different occasions.

The purpose of this website is to provide the bakery with an online presence where customers can:

* View available products
* Learn more about the bakery
* Browse product images
* Submit custom cake enquiries
* Find contact information
* View the bakery's location
* Access the website on desktop and mobile devices

This project was developed as part of my **Web Development Portfolio of Evidence (POE)**.

# Website Pages

## Home

The Home page introduces **Sweet Treats by Abigail** and welcomes visitors to the website.

It includes featured bakery information, images and links to other important sections of the website.

## About

The About page provides information about the bakery's story, mission, vision and passion for creating cakes and desserts.

## Products

The Products page displays the bakery's range of cakes and desserts available to customers.

Product images are included to help customers view examples of the bakery's work.

## Enquiry

The Enquiry page allows customers to request quotations and submit enquiries about custom cake orders.

Customers can provide information about the type of product or cake they are interested in.

## Contact

The Contact page provides:

* Contact information
* Business hours
* Bakery location
* Social media information
* Google Maps integration
* Customer contact form

# Installation

To run the website locally:

1. Clone the repository:

```bash
git clone https://github.com/ethanbillett2004/WEDE5020_POE_PART2.git
```

2. Open the project folder.

3. Locate the `index.html` file.

4. Open `index.html` in your preferred web browser.
